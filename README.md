# OriginFX RFCs

> Request for Comments — the process for proposing significant changes to OriginFX.

---

## What is an RFC?

An RFC (Request for Comments) is how the OriginFX community proposes and discusses significant changes — new features, architectural decisions, breaking changes, or anything that affects the project direction.

Small bug fixes and minor improvements do not need an RFC. When in doubt, open a Discussion first.

---

## When to Write an RFC

Write an RFC when you want to:

- Add a major new feature or subsystem
- Change the architecture in a significant way
- Deprecate or remove existing functionality
- Establish a new convention or standard across the codebase

---

## The RFC Process

1. **Fork** this repository
2. **Copy** `0000-template.md` to `text/0000-your-feature-name.md`
3. **Fill in** the RFC template
4. **Submit a pull request** — the number assigned to your PR becomes your RFC number
5. **Discuss** — the community and maintainers will comment on the PR
6. **Decision** — maintainers will mark the RFC as `accepted`, `postponed`, or `closed`
7. **Implementation** — accepted RFCs can be implemented. Link the RFC in your implementation PR.
